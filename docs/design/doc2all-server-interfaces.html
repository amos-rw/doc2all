Every call passes these checks

  1. HTTPSNothing travels unprotected. Security headers on every answer
  2. Is this call listed?A call that is not marked open needs a sign-in
  3. Form tokenA change is accepted only with the token our own page holds
  4. SessionReal, not older than 30 minutes of rest, and in the right step
  5. Role and ownerOne place decides. Someone else's item is Not found
  6. InputType, size and allowed values. Extra fields are ignored
  7. LimitsToo many tries are refused
  8. Log and answerImportant actions are logged. Errors are plain, with no inside details

When the server says no

400Something in the request is wrong
401Sign in first
403Do the second step again
404Not found. Also the answer for another person's item and for admin pages without the role
429Too many tries, come back later

What no browser can ask for

Delete after 24 hoursA server timer. No call starts or stops it
Make an administratorA command on the server. No call can give the role
Check the audit log fingerprintsA command on the server
The sandbox runnerReceives a job and a copy of the file. It has no address the browser can reach

Five decisions

  1. Reset with a passkey: If the account has a passkey, a password reset asks for it too.Someone who gets into the mailbox still cannot take the account. With email codes only, the emailed code is the second step, so a passkey protects better.
  2. Lost passkey: Email codes can be stopped only while the account has at least two passkeys.If one device is lost, the other still opens the account. Losing every passkey and forgetting the password locks the account for good.
  3. Yes, it was me: This answer asks for the second step again.A person at your open computer cannot hide a security notice.
  4. Confirmed time: A second step done again counts for 5 minutes.Long enough to make a change, short enough to be safe.
  5. Create account: A known email gets the same answer, and its owner is told by email.Nobody can use this form to find which emails have accounts.
