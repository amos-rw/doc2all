    Design note

    Menu rules

    The menu changes with where the user is. It is hidden where it would only distract.

    Before sign-in

    No menu. Only the logo, with Privacy, Cookies and About at the bottom. Screens 1 to 4.

    Signed in

    Tools and History, the bell, and the profile menu with Settings and Sign out. Screens 5 to 10.

    Admin

    Audit log and Records replace Tools and History. Same bell and profile. Screen 11.

    Pop-ups

    While a question is open, the menu is dimmed until it is answered. Screens 6, 9 and the session-ended message.

    On a phone

    The top bar shows only the logo. A bottom bar has Tools, History, Alerts and Profile. It is hidden before sign-in and during pop-ups.
